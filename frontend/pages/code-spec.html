SpecPilot reads the code without running it, and deletes the downloaded copy as soon as the analysis is built.

Add /tree/branch-name to the link to use a branch other than the default.

  1. On GitHub open Settings, Developer settings, Personal access tokens, Fine-grained tokens, then Generate new token.
  2. Choose Only select repositories and pick just this one.
  3. Under Repository permissions set Contents to Read-only. Set a short expiry, such as 7 days.

The token is used once to download the code. It is not saved and the field is cleared afterwards. You can delete the token on GitHub when you are done.
